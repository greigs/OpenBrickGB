### Directory overview

- 3D Printed Parts: STL files for custom spacers and assemblies used inside the LEGO shell.
- Bill of Materials: CSVs listing components for the main PCB, button PCBs, and other parts.
- ButtonBoard PCBs: KiCad project assets and Gerbers for the button and D‑pad PCBs.
- Datasheets: Reference PDFs for key components (LCD, charger, amp, logic, regulators, etc.).
- Main PCB: KiCad project, fabrication outputs (Gerbers/DRLs), and pick‑and‑place (CPL) for the main board.
- Reference 3D Models: OBJ files used for fit checks and visualization of assemblies.
- Reference Bricklink Studio Designs: BrickLink Studio `.io` design files and a reference image for the LEGO build.
